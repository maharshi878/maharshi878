## `> LIVE PRODUCTS`

### ◆ [FreelanceCFO](https://freelancecfo.online) `— LIVE`
> **The financial command center for freelancers.**

Freelancers don't get predictable paychecks. One month $8,000. Next month $900. Every existing finance tool assumes a salary. FreelanceCFO was built for the feast-or-famine reality.

**The question it answers:** *"If I stopped getting clients today — how long could I survive?"*

```
→ Runway calculator with burn-rate projection
→ Irregular income budgeting (no fixed paycheck assumed)
→ Federal + self-employment tax estimation
→ Client profitability by effective hourly rate
```
`React` `TypeScript` `Supabase` `Tailwind` `Vite` `Vercel`

---

### ◆ [TrustLens](https://trust-lens-mvp.vercel.app) `— EARLY ACCESS`
> **Digital content forensics for everyone.**

AI tools generate hyper-realistic images, videos, UPI receipts, and documents. TrustLens doesn't just ask *"is this AI?"* — it reconstructs **how** content was created, what risk it poses, and whether it should be trusted.

```
→ Reality Trace™ — creation path reconstruction
→ TruthScore+ — financial, social & identity risk scoring
→ Source Match Shield™ — perceptual hash + web matching
```
`Python` `Computer Vision` `React` `TypeScript`
